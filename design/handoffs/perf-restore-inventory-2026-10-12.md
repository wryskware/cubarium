All review IDs F1–F13, H1–H2, M1–M7 and L1–L9 appear above. Physical panel verification and native Windows/macOS execution are not claims made by this inventory.


Acceptance tests: GPU wgpu_backend/perf_tests.rs (120 unchanged + 120 moving lit frames, 120 unchanged + 120 moving flat/present frames, validation isolation, readback failure and displaced timing); pipeline_cache.rs tests (reload/use, truncated/random/foreign files and interrupted rename); wgpu_backend/window.rs mode selection; host warm.rs completion_tests and window_target.rs mailbox tests. Creation counters are monotonic, so recreating and dropping an object cannot hide behind an unchanged live count. Native live buffers/groups/queries/textures/views/samplers are also checked. Full suites and the strict matrix run in the detached chain; their results must not be claimed before its logs exist.

Parent checks: the safe API limits above (scanout export, acquired surface views and cache merging), window snapshot GPU copy cost and native macOS event-loop behavior. Remote window benchmarks use a private Xvfb display; retain that distinction when comparing the original compositor baseline. No ecological values, art choices, shaders, source hashes or shader interfaces were changed.
