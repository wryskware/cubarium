# ENGAGE: a staged encounter between a loftstrider family and a Veilhound pack

## Rules

Read `design/handoffs/behaviour-ai-worker-rules-2026-10-12.md` first. It covers windows, the
5-minute limit, labd, builds, tests, knobs, saves, commits and the return format.

## Why

This is package 1 of `design/behaviour-ai-2026-10-11.md` (§8). The design changes how
loftstriders defend their calves and how Veilhounds hunt as a pack (read §0, §3, §4 and §7
for the intent). Before anything changes, we need today's behaviour on video, and baseline
numbers from a staged encounter that later packages rerun on matched starts. Live worlds hold
too few encounters: about one family–pack engagement per eight 10-minute windows. The harness
is also the brains' staged-encounter episode source later (§10.4, §11.7), so build it as a
reusable library function plus a thin example, not a one-off script.

## Do

Build the engagement harness of §7, "The engagement harness". It's an existing-pattern port:
see `crates/cubarium/examples/*_probe.rs` (for example `defence_probe.rs`, `hunter_probe.rs`),
`crates/cubarium-search/src/es/voxel/live/world.rs` (`training_config`, `found_world_from`),
the scenario maps in `config/scenarios/`, and `scripts/studies/batch.py`.

1. **Scene.**
   - A flat scene: `config/scenarios/train-flat.toml`, or a hand-built flat world if that
     plain is too narrow. The family needs room to flee and the pack room to encircle: at
     least several loftstrider body lengths of open, connected ground. Say which you used
     and why.
   - It holds one loftstrider family against one Veilhound pack, both driven by today's
     heuristics. No other fauna by default, with a flag to add the usual prey.
   - Compositions: two adults and a calf (the main case); two adults and no calf; a lone
     calf.
   - Pack sizes: 2, 3 and 4.
   - The calf is the adults' real young: `Animal::mother` set, as at birth. The pack is one
     pack record with a den.
2. **Placement from a seed.** The episode seed alone fixes the terrain seed, the family's
   placement, the pack's placement and bearing, each body's starting energy and age within a
   stated range, and the sim's RNG.
   - The same seed gives the same start in every arm. These are the "matched starts" of §8
     row 1 and §11.7: later arms (kick on/off, calls on/off, brain versus heuristic) rerun
     identical starts.
   - Starting hunger: the pack hungry enough to hunt, the family fed. Say how you set it.
3. **Run.**
   - Each episode runs at most 5 sim-minutes (a knob in the harness config).
   - It ends early once the outcome is decided: a loftstrider killed and eaten from, the pack
     given up and leaving, or every hound dead or fled.
4. **Outcome row per episode** (JSON lines or TSV, one file per arm):
   - seed, arm, composition, pack size;
   - outcome: calf killed, adult killed, pack gave up, or timeout;
   - time to outcome;
   - hound wounds (total and the worst) and hound deaths;
   - calf and adult wounds;
   - counted apart, as far as today's code exposes them: encounters (a hound senses the
     family), tests (an approach then a break-off), chases, captures (a bite that holds), and
     kills (§7's last readout). If a count needs an event the code doesn't record, add the
     smallest read-only hook, or leave it out and say so.
   - Read outcomes from sim state and events, not by inferring from positions.
5. **Arms now:** composition × pack size. The kick and calls arms come later, when those
   mechanisms exist (packages 3–4). Make arms a config list, so adding one is a config line
   plus a flag, not a code change.
6. **Batch.**
   - A labd spec runs 50 episodes per arm (the count is a knob) through the batch kind.
   - Submit it yourself once a short `lab quick` run of a few episodes passes.
   - A reduce step, chained in the spec if the kind allows, writes a per-arm table: outcome
     shares with counts, median time to outcome, and wound and death totals.
   - Then hand back at once with the job id. Don't wait on it.
7. **Video.**
   - One episode of the main case (two adults and a calf against 3 hounds) rendered headless
     to MP4: real time, x264, yuv444p, crf 12.
   - Pick a seed where something happens. Find it from the quick run's rows, not by
     watching.
   - Written to `/home/wrysk/wryskware/cubarium/art/gen/runs/engage-2026-10-12/`.
   - This is today's behaviour only, one panel. Later packages add the side-by-side.
   - Find the repo's headless capture path (`--gpu-target headless --gpu-capture DIR`, or the
     voxel viewer's equivalent loading a saved episode start). If rendering needs a long
     run, put it in the same labd job.

## Boundaries

- **No behaviour change.** Today's heuristics drive everything.
- **Fauna crate.** `crates/cubarium-voxel-fauna/` is being reworked in parallel by the
  CONTRACTS package. Avoid editing it. If you must add a read-only accessor or event counter
  there, keep it tiny and in its own commit, and name it in the handback.
- **Defaults and presets** stay unchanged. The harness config is new and lives with the
  harness.

## Checks

- A test that one short episode (a few hundred ticks) founds the scene from a seed and
  writes a well-formed row.
- A test that the same seed gives the same start in two arms: body positions and energies
  equal at tick 0.
- No assertion on outcomes or rates.

## Return

The rules file's format, plus:
- the labd job id and output paths;
- the quick run's rows, in brief;
- the MP4 path, or where it will land;
- anything about today's behaviour that looks broken: for example the pack never engaging, or
  the family never fleeing.
